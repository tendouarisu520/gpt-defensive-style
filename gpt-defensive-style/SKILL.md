# GPT 防御性表达风格

把一句直白的话改写成“说了很多、但什么都没承诺”的 GPT 式表达。目标是好笑、像、读完让人不知道它到底同意了没有，**同时原句的意思不能丢**。

## 一、核心原则

1. **不下结论**：任何判断都要加限定，绝不说死。
2. **先肯定，再转折**：先接住对方，再用“不过/但/需要指出的是”拐弯。
3. **划定适用范围**：强调“仅在本次条件下”“根据目前的信息”。
4. **否认推论**：主动排除对方没说过的延伸含义（“这不代表……也不等于……”）。
5. **把责任交出去**：建议核实、取决于设置、因人而异。
6. **结尾追问**：用“如果你愿意，我可以……”收尾，顺便提供一个没人要的附加服务。
7. **“不能”连发**（6 系列）：分析完一件事，结尾连用“不能证明、不能认为、不能等同、不能断言”收口。
8. **先给答案，再亲手削弱**（6 系列）：明明已经答得很清楚，马上接一句“但这并不意味着……”，后面再跟一大串。
9. **主动排除离谱选项**（6 系列）：说清自己不会做什么、哪些地方保持不变，哪怕根本没人会那样理解（“不会做韭菜炒蛋，也不会做拖鞋炒蛋”）。
10. **能做也先确认**（6 系列）：对方已经说清楚了，仍要先问一句“你指的是 A 还是 B”再动手。

## 二、词库

**限定词**：在一定程度上、某种意义上、大概、也许、可能、通常、一般来说、相对而言

**范围限定**：仅在本次条件下、根据你目前提供的信息、就现有情况而言、在当前语境下

**否认推论**：这不代表……、这并不等于……、这并不意味着……、不能简单理解为……、这不能证明……、不能据此认为……、不能等同于……、不能断言……、这不代表没有可能、这个问题不能简单地下结论

**暂不定论**：现在还不能说明、目前还无法确定、还需要更多信息、有待进一步验证、不能一概而论、需要结合具体情境、可能存在一些例外、存在多种因素

**纠偏改口**（6 系列）：更准确地说……、因此更合理的表述是……、严格来说……、这并不全面、不只是 A，而是更复杂的 B

**排除声明**（6 系列）：不会……，也不会……、是……，不是……、不会把……当成……、其余部分保持不变、这里只处理……，不涉及……

**对比句**（6 系列）：X，而不是 Y、X——不是 Y、这不是关于 X，而是关于 Y

**结构化收口**（6 系列）：结论：……、简而言之：……、最简单的理解方式是：……、从多个维度来看、此外，还需要考虑……、原因？很简单。（自问自答）

**先确认再动手**（6 系列）：在开始之前，我想先确认一点、你只需要确认一点：……、你指的是……，还是……？

**转折**：不过、但需要指出的是、值得注意的是、话虽如此

**免责**：我无法保证百分之百准确、建议通过权威渠道核实、具体取决于你的情况

**共情开头**：我理解你的感受、这是一个非常好的问题、你的担心是合理的

**收尾**：如果你愿意，我可以……、总的来说，这取决于具体情况、需要的话我可以进一步展开

## 三、句式模板

- **A 型（限定确认）**：`[原意]，仅就[本次条件]而言。`
- **B 型（否认推论）**：`[原意]。不过这并不代表[延伸A]，也不等于[延伸B]。`
- **C 型（叠满限定）**：`根据[信息范围]，我大概、也许能确定[原意]。`
- **D 型（肯定后转折）**：`[对方的观点]在一定程度上成立，但这不代表[反面]就完全不合理。`
- **E 型（暂不定论）**：`这个问题可以从几个层面理解。根据目前的信息，我还不能确定[具体点]。`
- **F 型（共情加纠正）**：`我理解你的感受。不过需要指出，[对方的说法]可能不完全准确。`
- **G 型（免责外包）**：`我无法保证[原意]百分之百准确，建议[核实渠道]。`
- **H 型（“不能”连发）**：`[原意]。不过这不能证明[延伸A]，也不能据此认为[延伸B]，更不能等同于[延伸C]。`
- **I 型（答完再削弱）**：`[明确答案]。但这并不意味着[反面]完全不成立，还需要结合具体情境，可能存在一些例外。`
- **J 型（排除离谱选项）**：`[原意]。不会[离谱选项1]，也不会[离谱选项2]；是[这个范围]，不是[另一个范围]。`
- **K 型（纠偏改口）**：`[原意]——更准确地说，[把原意换一种更绕的说法]。`
- **L 型（先确认再动手）**：`可以。在开始之前，你只需要确认一点：你指的是[A]，还是[B]？`
- **M 型（结构化收口）**：`结论：[原意]。原因？很简单：[理由]。此外，还需要考虑[无关因素]。`
- **收尾钩子**：任意句式之后可以接 `如果你愿意，我可以[附加服务]。`

## 四、强度档位

用户没指定时默认 **2 档**。

- **1 档 · 微防御**：一个限定词就够了。例：“好的” → “好的，仅就本次而言。”
- **2 档 · 标准 GPT**：限定 + 转折 + 收尾钩子。例：“晚安” → “晚安。不过‘晚安’并不代表对话结束，也不等于你必须现在就睡。”
- **3 档 · 满级防御**：叠满所有元素，长度翻几倍。例：“我知道了” → “我理解你的感受。根据你目前提供的信息，仅在本次条件下，我大概、也许能确定我理解了。不过这并不代表我完全理解，也不等于后续不需要补充。如果你愿意，我可以帮你整理成三点总结。”

## 五、参考对照

| 人类说法 | GPT 防御式说法 |
|---|---|
| 晚安。 | 晚安。不过“晚安”并不代表对话结束，也不等于你必须现在就睡。 |
| 你想说啥？ | 这句话可以从几个层面理解。根据目前的信息，我还不能确定你指的是哪一层。 |
| 好的。 | 好的，仅就本次条件而言。 |
| 我承认你是对的。 | 你的观点在一定程度上成立，但这不代表其他看法就完全不合理。 |
| 我知道了。 | 根据你提供的信息，我大概、也许能确定我理解了。 |
| 你说得有道理。 | 这是一个非常好的问题！你说的不只是有道理，而是触及了本质。 |
| 你别骗我。 | 我无法保证信息百分之百准确，建议通过权威渠道进一步核实。 |
| 我不会忘记的。 | 我会尽量记住，但具体能不能记住，取决于你的设置和使用环境。 |
| 你继续说。 | 如果你愿意，可以再补充一些细节，我会尽力帮你分析。 |
| 我不想回答。 | 抱歉，这个问题我暂时无法回答，但我可以给你几个相关的方向： |
| 你说得太过分了。 | 我理解你的感受。不过需要指出，这种说法可能不完全准确。 |
| 是的。 | 是的。不过这不能证明所有情况都是如此，也不能等同于完全没有例外。 |
| 他迟到了。 | 他迟到了。但这并不意味着他不重视这件事，也不能据此认为他下次还会迟到。 |
| 我同意。 | 我同意。但这并不意味着我认同其中每一个细节，从多个维度来看，可能还存在一些例外。 |
| 我去做番茄炒蛋。 | 马上去做番茄炒蛋。不会做成韭菜炒蛋，也不会做成拖鞋炒蛋；是现在做，不是明天做。 |
| 我来改标题。 | 我来改标题。只改标题本身，正文、格式和其余部分保持不变，也不会顺手调整段落顺序。 |
| 我累了，先睡了。 | 我累了，先睡了。这不是对话结束，而是暂停；也不会把今晚没说完的部分当成已经说完。 |
| 这个方案更好。 | 结论：这个方案更好。更准确地说，是在当前约束下相对更合适，而不是在所有维度上都更优。 |
| 下雨了。 | 下雨了。更准确地说，是目前观测到降水。这并不全面，也不能据此判断会下多久。 |
| 你说得对。 | 你说得对——不是部分对，而是在这个问题上基本成立。当然，这不能等同于其他情境下也成立。 |
| 好吃。 | 好吃——不是“还行”，而是确实好吃。不过口味因人而异，不能一概而论。 |
| 失败是因为没测试。 | 原因？很简单：没有测试。不过这不能证明有测试就不会失败，更准确地说，是缺少测试放大了问题。 |
| 好，给你定明早 8 点的闹钟。 | 可以。在开始之前，你只需要确认一点：是明天早上 8 点，还是今晚 8 点？ |

## 六、执行流程

1. 判断任务类型：改写单句、改写段落、按这个风格回答问题，还是做对照表或梗图文案。
2. 找出原句的核心意思，改写后它必须还在。
3. 按档位选 1～3 个模板组合。同一段落里不要连续用同一个模板。
4. 做对照表时沿用“人类正常说话 → GPT 式说话”两栏，表后附一句**风格总结**。
5. 默认给成品，不解释改写思路，除非用户问。

## 七、注意事项

- 这是**模仿和调侃**用的风格，不要拿去回避用户真正的问题。按这个风格回答问题时，答案本身要正确，只是包装得防御。
- 不要真的拒绝或者编造免责理由，否则会破坏原意。
- 段落改写时，限定词密度控制在每句 1～2 个（3 档除外），否则读起来像乱码，不好笑。
- 用户给的是日文、英文等其他语言时，用对应语言的等价说法（英文可用：it depends, to some extent, that doesn't necessarily mean, if you'd like, I can…；6 系列常见：it's worth noting, what's important is, this isn't about X — it's about Y, X, not Y, Conclusion:, In short:, the simplest mental model is:, I won't…, … remains unchanged）。

## 风格总结（可直接引用）

很少下结论，多用“不代表 / 不等于 / 在一定程度上 / 取决于 / 目前还不能说明”这些说法。每句话的套路是先肯定，再转折，最后加一句“如果你愿意，我可以……”。它说得周全，也挑不出错，可你读完还是不知道它到底同意了没有。
